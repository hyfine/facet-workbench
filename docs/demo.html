Walkthrough transcript

  1. Trace a matching block. Hover over engine and channels. A translucent ribbon connects each to its reordered counterpart. Switching to ordered arrays exposes two additional changes.
  2. Repair a document. JSON Studio reports each repair. Collapse the tree, expand it, then open the formatted text in a larger view.
  3. Decode and keep working. Base64 becomes readable text; send it straight to JSON Studio to inspect the decoded object.
